# 공부핏 (StudyFit) MVP

학생용 공부 관리 PWA입니다. HTML/CSS/JavaScript만 사용하며 별도 빌드 단계가 없습니다.

## 포함 기능
- 25분 집중 타이머
- 완료한 집중 세션의 공부 기록
- 오늘의 할 일 체크리스트
- 시험 D-day 등록
- 일일 공부 목표
- 브라우저 로컬 저장
- PWA 매니페스트 및 서비스 워커

## 실행 방법
1. ZIP 압축을 풉니다.
2. `index.html`을 브라우저에서 열어 기본 기능을 테스트할 수 있습니다.
3. 설치 버튼/PWA/서비스 워커는 HTTPS 또는 localhost 환경에서 동작해야 합니다.
4. 무료 정적 호스팅에 `index.html`, `manifest.json`, `sw.js`, `icon.svg`를 업로드하면 HTTPS 주소로 배포할 수 있습니다.

## 중요한 한계
- 데이터는 현재 브라우저의 localStorage에 저장됩니다. 기기 간 동기화/계정/클라우드 백업은 없습니다.
- 광고 슬롯은 자리표시자이며 실제 광고가 아닙니다. 광고 사업자의 승인, 개인정보/쿠키 고지, 서비스 정책 준수가 필요합니다.
- AdSense 등 일부 광고 서비스는 계정 소유자 만 18세 이상 및 사이트 승인 요건이 있습니다. 미성년자는 나이 제한을 우회하지 말고 보호자와 함께 적합한 계정/정책을 확인하세요.
- 앱스토어에 네이티브 앱으로 올리려면 별도 패키징, 심사 및 각 스토어 정책 확인이 필요합니다.
- 타이머가 실행 중인 동안 브라우저가 종료되거나 운영체제가 작업을 중단하면 세션이 정확히 기록되지 않을 수 있습니다.

## 다음 단계
사용자 테스트 → 개인정보 처리방침/이용 안내 → 안정성 개선 → 실제 광고 승인 여부 확인 → 사용자 수요가 확인되면 계정/동기화 기능 검토.
